# Todo App (Android)

A simple Android application built using Kotlin that allows users to create and view notes. This project demonstrates basic Android development concepts including UI design, data handling, and navigation between screens.

## Features

- Add notes with title and description
- Display notes in a list
- View note details on a separate screen
- Basic navigation between activities

## Tech Stack

- Kotlin
- Android SDK
- XML for UI design

## Project Structure

- `MainActivity.kt` – Handles main screen and note input
- `DetailActivity.kt` – Displays selected note details
- `NoteAdapter.kt` – Custom adapter for ListView
- `activity_main.xml` – Main UI layout
- `activity_detail.xml` – Detail screen layout
